InstExt - notices
=================

InstExt extracts the contents of Windows installers without running them. It is licensed under the
MIT License, see LICENSE.txt. This file acknowledges the works that its format readers were written
from. When InstExt is built, the licenses of the libraries it is built with are appended, and the
result is installed with the program as THIRD-PARTY-NOTICES.txt.
